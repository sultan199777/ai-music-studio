# Il tuo spazio «basi IA» senza limiti (gratis, dall'iPhone)
Come lo spazio di separazione, ma per CREARE basi con ACE-Step 1.5 (licenza MIT). Niente limite giornaliero: è tuo.

1. huggingface.co → la tua foto → **New Space**: nome `sultan-crea`, License **mit**, SDK **Gradio**, Hardware **CPU basic · FREE**, **Public** → Create.
2. **Files → + Add file → Create a new file**, tre volte (tieni premuto sul testo del link → Seleziona tutto → Copia → incolla):
   - `app.py` ← https://raw.githubusercontent.com/sultan199777/ai-music-studio/main/space-crea/app.py
   - `requirements.txt` ← https://raw.githubusercontent.com/sultan199777/ai-music-studio/main/space-crea/requirements.txt
   - `packages.txt` ← scrivi due righe: `ffmpeg` e `git`
3. Aspetta **Running**: la prima volta 10-20 minuti (scarica circa 6 GB di modello, una volta sola).
4. Nell'app: **1 Testo → ✨ Base IA → «Il tuo spazio basi IA»** → scrivi `tuonome/sultan-crea`.
5. Premi «✨ Crea una base IA».

Misurato (computer di prova, 4 CPU): 30 s di base in 34-59 s, 90 s in 156 s, memoria massima 8,8 GB (lo spazio gratuito ne ha 16).
Lo spazio gratuito ha 2 CPU: aspettati circa il doppio (stima: 3-5 minuti per 90 secondi). Se resta fermo a lungo, si addormenta: la prima richiesta dopo una pausa ci mette qualche minuto in più.
